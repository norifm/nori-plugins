# SoundCloud

Install it, turn it on, then add a SoundCloud profile. Signed in, Library is your SoundCloud library:
your likes in Favorites, your playlists and albums (made and liked), and those you follow as Artists.

## Good to know

- This is best effort: SoundCloud can stop it working at any time.
- Tracks only subscribers can hear in full, and those SoundCloud serves only encrypted, are left out,
  and so are albums with nothing else. Many labels' albums are like that.
