# Remote switch

Remote switch puts a **Remote control** switch on the **Playing on** sheet. Turn it off, and nori stops
talking to your other devices for a while. They do not list this device and cannot control it, and it
cannot host a jam.

Your **Remote control and jams** setting stays as you set it. nori follows it again when you turn the
switch on or the plugin off. When that setting is off, the switch cannot turn remote control on.
