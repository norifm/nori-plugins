# Soundcore

Battery, noise control and settings for Soundcore earbuds and headphones, in nori's player.

Tested on the Liberty 4 NC. On other models, unexpected things may happen.

The headphones' equalizer stays at 0 dB, so it doesn't stack with nori's.

Close the Anker Soundcore app while you use this. The headphones talk to one app at a time.

Based on [OpenSCQ30](https://github.com/Oppzippy/OpenSCQ30) by Kyle Scheuing, GPL-3.0-or-later.
